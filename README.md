# Virat Kohli Performance Dashboard

## 📊 Project Overview

An interactive Power BI dashboard analyzing Virat Kohli's
batting performance across ODI, Test, and T20I formats.

The dashboard provides insights into career performance,
batting milestones, format-wise performance, yearly trends,
and selected-year analysis.

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Power Query
- Excel
- Data Visualization

## 📌 Dashboard Pages

### 1. Overview
Provides a high-level summary of career performance,
including total runs, batting average, strike rate,
highest score, centuries and half-centuries.

### 2. Performance Analysis
Analyzes runs, batting average, strike rate, highest score,
dot-ball percentage and career phases across formats and years.

### 3. Milestones & Batting Analysis
Analyzes 50s, 100s, boundaries, conversion rate,
fours, sixes, balls faced and dismissals.

### 4. Details
Provides year-level drill-through analysis with
format-wise performance and milestone breakdown.

## 📈 Key Insights

- Career performance across multiple cricket formats
- Year-wise run trends
- Format-wise batting performance
- 50s vs 100s comparison
- Boundary analysis
- Career phase analysis
- Selected-year drill-through analysis
